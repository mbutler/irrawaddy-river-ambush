**Total runtime:** ~42 minutes  
**Read rate:** ~140 words/minute  
**Format:** `[ANIM:]` = motion graphics cue | `[SFX:]` = optional sound | `[PAUSE:]` = beat  

Composition IDs in `[ANIM:]` match Remotion exports in `remotion/`.

### Production note (full VO + rough cut)

This script is **record-ready** as a single pass. Quantities use digits (40 hexes, EAL 12, 15%) — pronounce **zero-one** for a d100 roll of 01; **aught**/**oh** for leading zeros in roll callouts if you prefer broadcast style (e.g. roll oh-eight for 08). Lay the full VO in your NLE first, then swap Remotion exports section by section. Phoenix Command numbers (EAL, odds, rolls, PEN/DC) match `scenario.ts` and `node scripts/log-beats.mjs`. Tactical map visuals use `river-graphic.png` and `boat.png`; narration hex ranges describe the **abstract kill zone**, not literal pixels on the artwork.

## ACT 3 — PHOENIX COMMAND PRIMER (16:00 – 22:30)

### SC-020 · 16:00 – 18:00

`[ANIM: FR-030 Phase timeline. PhoenixPrimer composition. SIMULATION MODE.]`

**VO:**  
If you have never played Phoenix Command, this next section is your entire ruleset for the video.

Phoenix Command is a small-arms combat simulation published in the 1980s and still unmatched in granularity. It treats combat not as hit points and modifiers, but as physics, anatomy, and human reaction time.

`[ANIM: FR-030 — one Phase bar divides into 4 Impulse segments, 0.5s each labeled.]`

Time is measured in Phases. 1 Phase equals 2 seconds of real time. Each Phase divides into 4 Impulses of 0.5 second. Everything happens simultaneously within an Impulse — all shooters fire, all bullets fly, all wounds are checked.

`[ANIM: FR-031 Combat Actions bar for Carter — 2-1-1-1.]`

Every character has Combat Actions per Phase — derived from Strength, Agility, Intelligence, skill level, and encumbrance. Lieutenant Carter, a Crack soldier, has 5. That is 2 Actions in Impulse 1, 1 in Impulse 2, 1 in 3, 1 in 4 — Table 1-E.

Moving 1 hex costs 1 Action. Assuming a firing stance costs 2. A snap shot uses 1 Action of aim-and-fire combined — you do not aim for 1 Action and shoot on a second. Automatic weapons fire 1 burst per Impulse maximum.

Unused Actions are lost. Combat is wasteful and frantic.

---

### SC-021 · 18:00 – 20:30

`[ANIM: FR-032 empty EAL panel. FR-033 populates row by row. EALDemo composition.]`

**VO:**  
When someone shoots, we calculate the Effective Accuracy Level — the EAL.

`[ANIM: Each modifier row slides in with stagger — see style guide 80ms.]`

Each factor contributing to accuracy is an Accuracy Level Modifier — an ALM. Add them together.

Aim Time plus Skill Accuracy Level — how long you aimed and how good you are. Range — farther is harder. Movement — targets and shooters both. Situation and stance — bipod mounted, hip fire, kneeling braced. Visibility — monsoon haze. Target size — a standing man on an open raft is a large target for burst elevation; a head looking over hard cover is a small one.

For automatic fire, subtract the weapon's SAB — sustained automatic burst penalty.

`[ANIM: EAL total counts up. Odds ring fills. FR-034.]`

The sum is clamped between -10 and +28. Cross-reference Table 4-G — the Odds of Hitting. That gives a percentage.

Roll 2 ten-sided dice as a 0 to 99 number. Less than or equal to the odds — hit. Greater — miss.

`[ANIM: FR-035 dice lock at 22. HIT flashes green.]`

That is the core loop. Everything else is consequence.

### SC-022 · 20:30 – 22:30

`[ANIM: FR-037 hit location silhouette. FR-038 KV gauge.]`

**VO:**  
On a hit, roll hit location. Cross-reference Penetration against Effective Protection Factor. Raft troops have no armor — EPF 0. Look up Physical Damage on Table 6-A.

Physical Damage measures wound severity — from superficial to instantly fatal. A thigh flesh wound might be 3 PD. A heart hit might be 4000.

`[ANIM: PD counter ticks up on silhouette.]`

Each Impulse a character takes damage, check incapacitation. Compare total Physical Damage to Knockout Value on the Knockout Table. That gives an Incapacitation Chance — a percentage. Roll d100. If the roll is less than that chance, you fail — shock casualty, out of the fight. If the roll is equal or higher, you keep going.

`[ANIM: KV gauge — PD 56 vs KV 35, IC 25%, roll 18, FAIL.]`

Veterans and recruits die the same way. Phoenix Command is honest about that.

`[ANIM: Brief code scroll — phoenix-functions effectiveAccuracyLevel, oddsOfHitting, hitDamage — monospace on dark.]`

I built the lookup engine in JavaScript — phoenix-functions — so every number you see on screen matches the rulebook tables exactly. No fudging. When the EAL panel says 43% for Carter's BAR burst, that is Table 4-G.
